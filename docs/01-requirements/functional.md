> Статус: черновик Обновлён: 2026-06-26 Автор: Архипов Григорий

Что сервис должен **делать**. Каждое требование — с идентификатором `FR-NN`, чтобы
на него можно было ссылаться из задач, тестов и ADR.

## Формат

```
FR-NN: <краткая формулировка>
  Описание: <подробности>
  Приоритет: обязательно | желательно | можно
  Статус: предложено | принято | реализовано
  Связи: <ссылки на ADR / тест-кейсы / задачи>
```
