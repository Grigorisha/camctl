## Ограничения и допущения

*Внешние рамки, которые мы не выбираем, но обязаны учитывать.*

- Аппаратные SDK: Galaxy / `libgxiapi` (Daheng), GuideUSBCamera / USB3.0 SC-SDK (тепловая).
- **Язык релиза: C++** ([ADR-0003](../02-architecture/decisions/0003-service-language-cpp.md)) — ради контроля и низкой задержки. Python (`viewer_qt.py`, `Test.py`) — только прототип/тесты.
- Интерфейс подключения: USB 3.0.
- Кодек и транспорт видео: H.264 поверх RTP, сессия по RTSP (см.
[ADR-0002](../02-architecture/decisions/0002-streaming-transport.md)).
- Инструмент стриминга: `ffmpeg` — уже используется в проекте и на стороне клиента коллеги.
- ...
