# Нефункциональные требования (НФТ)

> Статус: черновик
> Обновлён: 2026-06-26
> Автор:

Каким сервис должен **быть**: производительность, надёжность, ограничения. Указывайте
измеримые целевые значения там, где это возможно — иначе требование нечем проверить.

| ID | Категория | Требование | Целевое значение | Как проверяем |
|----|-----------|------------|------------------|---------------|
| NFR-01 | Производительность | Частота кадров RGB-потока | ≥ __ FPS при __×__ | замер, см. [../08-testing/](../08-testing/) |
| NFR-02 | Производительность | Частота кадров теплового потока | ≥ __ FPS | замер |
| NFR-03 | Задержка | Latency «сцена → кадр у потребителя» | ≤ __ мс | замер |
| NFR-04 | Надёжность | Восстановление после переподключения камеры | авто-reconnect за ≤ __ с | стенд |
| NFR-05 | Надёжность | Непрерывная работа без утечек | __ часов без роста памяти | мониторинг |
| NFR-06 | Ресурсы | Потребление CPU/RAM на поток | ≤ __ % CPU / __ МБ | профайл |
| NFR-07 | Переносимость | Поддерживаемые ОС/окружение | Linux x86_64 (gcc 13) | сборка/прогон |
| NFR-08 | Совместимость | Поддерживаемые модели камер | см. [../04-hardware/cameras.md](../04-hardware/cameras.md) | стенд |
| NFR-09 | Безопасность/доступ | Права на устройства `/dev/video*` | udev-правила, без root | проверка |
| NFR-10 | Наблюдаемость | Логи и метрики работы потоков | структурные логи | ревью |
| NFR-11 | Удобство сопровождения | Документация и журнал решений | актуальные docs/ | ревью |
