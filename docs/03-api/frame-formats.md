# Форматы кадров

> Статус: черновик
> Обновлён: 2026-06-26
> Автор:

Как сервис представляет кадры разных камер: пиксельформаты, битность, единицы
измерения, метаданные. Это контракт между захватом, обработкой и выдачей.

## Типы кадров


| Тип     | Источник      | Пиксельформат    | Битность    | Единицы значения | Примечание                                                                                    |
| ------- | ------------- | ---------------- | ----------- | ---------------- | --------------------------------------------------------------------------------------------- |
| RGB     | Daheng ME2P   | BAYER_GB8 → RGB8 | 8 бит/канал | яркость          | дебайеризация в сервисе (см. `Test.py`)                                                       |
| Thermal | USB3.0 SC-SDK | Mono16 / raw (?) | 16 бит (?)  | °C / отсчёты     | радиометрия, см. [../04-hardware/thermal-usb3-scsdk.md](../04-hardware/thermal-usb3-scsdk.md) |


*Поля со знаком (?) — заполнить по факту при работе с железом.*

## Метаданные кадра

Минимальный набор полей, сопровождающих каждый кадр:


| Поле               | Тип    | Описание                             |
| ------------------ | ------ | ------------------------------------ |
| `device_id`        | строка | источник кадра                       |
| `frame_id`         | целое  | порядковый номер                     |
| `timestamp`        | время  | момент захвата (для синхронизации)   |
| `width`, `height`  | целое  | разрешение                           |
| `pixel_format`     | enum   | формат пикселя                       |
| `stride`           | целое  | длина строки в байтах (выравнивание) |
| `exposure`, `gain` | число  | параметры захвата (если применимо)   |


## Преобразования

- **BAYER → RGB:** дебайеризация (в `Test.py` — `DxBayerConvertType.NEIGHBOUR`,
порядок каналов BGR).
- **Thermal raw → °C:** радиометрическое преобразование (формула/таблица от SDK).
- **Совмещение RGB ↔ thermal:** через калибровку (intrinsics/extrinsics),
см. глоссарий [../00-overview/glossary.md](../00-overview/glossary.md).
