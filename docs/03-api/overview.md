# API: обзор

> Статус: черновик
> Обновлён: 2026-06-29
> Автор:

Контракт сервиса для внешних потребителей: как управлять камерами и получать кадры.
Решение о конкретном транспорте оформляется как ADR.

## Открытый вопрос: транспорт

_Выбрать и зафиксировать в ADR (см. [../02-architecture/decisions/](../02-architecture/decisions/))._

| Вариант | Когда уместен | Заметки |
|---------|---------------|---------|
| CLI | Локальный запуск, скрипты, отладка | проще всего стартовать |
| REST/HTTP | Управление + метаданные, веб-клиенты | большие кадры тяжело гонять по HTTP |
| gRPC / стриминг | Потоковая выдача кадров с низкой задержкой | сложнее, но эффективнее для видео |
| Shared memory / сокет | Локальный высокочастотный поток кадров | минимальная задержка |

**Решено для видеопотока (data plane):** кадры камер отдаются по **RTSP/RTP в H.264**
(через `ffmpeg`) — см. [ADR-0002](../02-architecture/decisions/0002-streaming-transport.md).
Варианты выше остаются актуальны для **control plane** (управление, метаданные) — это
отдельное, ещё не зафиксированное решение.

## Принципы API

- Версионирование контракта (например, `/v1/...` или версия в сообщении).
- Явные коды/категории ошибок (устройство не найдено, занято, нет прав, таймаут).
- Управление и поток данных можно разделить (control plane vs data plane).

## Операции (черновик)

| Операция | Назначение | Вход | Выход |
|----------|------------|------|-------|
| `list_devices` | Перечислить камеры | — | список устройств + параметры |
| `open` / `close` | Открыть/закрыть устройство | id устройства | статус |
| `configure` | Задать параметры (значениями или JSON-пресетом) | id, параметры / имя пресета | статус |
| `start` / `stop` | Старт/стоп потока | id | статус |
| `get_frame` / `subscribe` | Получить кадр / подписаться на поток | id | кадр(ы), см. [frame-formats.md](frame-formats.md) |

## Пресеты настроек (FR-13)

Настройки камер хранятся в именованных JSON-пресетах и применяются по имени через
`configure`:

- `indoor` — «в здании»;
- `outdoor` — «на улице»;
- `custom` — пользовательский (редактируется и сохраняется в JSON).

Пресет — это JSON с параметрами камеры (экспозиция, усиление, баланс белого, гамма,
частота кадров и т.п.). См. [FR-13](../01-requirements/functional.md).

## Модель ошибок

| Код/категория | Значение | Типичная причина |
|---------------|----------|------------------|
| `not_found` | Устройство не найдено | камера не подключена |
| `busy` | Устройство занято | уже открыто другим клиентом |
| `permission` | Нет прав | права на `/dev/video*` |
| `timeout` | Таймаут операции | нет кадров / зависание SDK |
