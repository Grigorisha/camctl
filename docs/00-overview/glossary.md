# Глоссарий

> Статус: в работе
> Обновлён: 2026-06-26
> Автор:

Единый словарь терминов проекта, чтобы в коде и документах слова значили одно и то
же. Дополняйте по мере появления новых понятий.

| Термин | Определение |
|--------|-------------|
| Камера глубины (depth camera) | Камера, измеряющая расстояние до точек сцены (стерео, ToF, структурированный свет) |
| Карта глубины (depth map) | Двумерное изображение, где значение пикселя — расстояние до объекта (обычно в мм) |
| Облако точек (point cloud) | Набор 3D-точек, восстановленных из карты глубины и параметров камеры |
| Тепловизор (thermal camera) | Камера, регистрирующая ИК-излучение; значение пикселя связано с температурой |
| Радиометрия | Привязка значений тепловизора к абсолютной температуре (°C/K) |
| RGB-камера | Обычная цветная камера видимого диапазона (в проекте — Daheng ME2P) |
| Захват (capture) | Получение одного кадра или потока кадров с устройства |
| Поток (stream) | Непрерывная последовательность кадров с камеры |
| Кадр (frame) | Одно изображение с метаданными (время, формат, параметры) |
| FPS | Кадров в секунду; ключевая метрика производительности потока |
| Latency (задержка) | Время от события в сцене до доступности кадра потребителю |
| Пиксельформат | Способ кодирования пикселя в памяти (например, BAYER_GB8, Mono16, RGB8) |
| BAYER | Мозаичный фильтр цвета на матрице; требует дебайеризации в RGB |
| Дебайеризация | Восстановление цветного изображения из BAYER-данных |
| Экспозиция | Время накопления света матрицей; влияет на яркость и смаз |
| Усиление (gain) | Аналоговое/цифровое усиление сигнала матрицы |
| Баланс белого (white balance) | Коррекция цвета под источник освещения |
| ROI (region of interest) | Выделенная область кадра для считывания/обработки |
| Калибровка | Определение внутренних/внешних параметров камеры (искажения, фокус, положение) |
| Внутренние параметры (intrinsics) | Фокус, главная точка, дисторсия конкретной камеры |
| Внешние параметры (extrinsics) | Положение/ориентация камеры в общей системе координат |
| Регистрация (registration) | Совмещение кадров разных камер (например, RGB и тепло) в одну систему координат |
| SDK | Набор библиотек для управления камерой (gxipy для Daheng, SC-SDK для тепловой) |
| gxipy | Python-SDK Daheng (Galaxy) для управления промышленными камерами |
| SC-SDK / plug617 | USB3.0 SDK тепловой камеры (см. [../04-hardware/thermal-usb3-scsdk.md](../04-hardware/thermal-usb3-scsdk.md)) |
