Детальное описание компонентов системы. На каждый компонент — назначение,
интерфейсы, зависимости, заметки. Шаблон ниже копируйте для новых компонентов.

## Шаблон описания компонента

### `<имя компонента>`

- **Назначение:** за что отвечает.
- **Входы:** что принимает (данные, события, конфигурация).
- **Выходы:** что отдаёт.
- **Зависимости:** от каких компонентов/библиотек/SDK зависит.
- **Состояние/lifecycle:** как создаётся, работает, освобождается.
- **Заметки/риски:** нюансы, ограничения, TODO.

## Компоненты

### Драйвер RGB-камеры (Daheng / gxipy)

- **Назначение:** обёртка над `gxipy` для управления Daheng ME2P.
- **Входы:** команды (открыть, настроить, старт/стоп), параметры (экспозиция, gain…).
- **Выходы:** сырые/декодированные кадры RGB.
- **Зависимости:** `gxipy`, см. [../04-hardware/daheng-me2p.md](../04-hardware/daheng-me2p.md).
- **Заметки:** дебайеризация BAYER_GB8 → RGB (см. `Test.py`).
