Где и как храним схемы архитектуры.

## Правила

- **По умолчанию — `mermaid` прямо в markdown.** Диаграмма версионируется как текст,
  видна в diff, не требует внешних инструментов. Примеры есть в
  [../overview.md](../overview.md).
- **Сложные схемы** (детальные, для презентаций) — исходник в `draw.io` (`.drawio`)
  рядом с экспортом в `.png`/`.svg`. Имя экспорта = имя исходника.
- Кладите файлы диаграмм в эту папку; в текстовых документах вставляйте ссылку/картинку.

## Виды диаграмм, которые стоит держать

- Контекст системы (кто взаимодействует с camctl).
- Конвейер данных (захват → обработка → выдача).
- Компоненты и их связи.
- Последовательности для ключевых сценариев (например, старт потока, переподключение).
