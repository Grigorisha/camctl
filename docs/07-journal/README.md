# Дневник разработки

> Статус: в работе
> Обновлён: 2026-06-26
> Автор:

Хронологический «черновик ума»: что сделал, что решил, на чём застрял, что попробовать
дальше. Низкий порог входа — пишите свободно, без вылизывания. Из дневника потом
вырастают ADR, задачи и тематические документы.

## Формат

- Один файл на день: `ГГГГ-ММ-ДД.md` (напр. [2026-06-26.md](2026-06-26.md)).
- Внутри — свободно, но удобно держать секции:
  - **Сделано** — что продвинулось.
  - **Решения** — что решил и почему (если значимо — вынести в
    [../02-architecture/decisions/](../02-architecture/decisions/)).
  - **Проблемы / застряло** — что не получилось, открытые вопросы.
  - **Дальше** — следующий шаг.

## Когда что-то «дозрело»

- Архитектурное решение → ADR.
- Задача → [../05-planning/backlog.md](../05-planning/backlog.md).
- Стабильное знание о камере/формате/требовании → соответствующий тематический раздел.
