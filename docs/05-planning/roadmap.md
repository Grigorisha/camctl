# Дорожная карта

> Статус: в работе
> Обновлён: 2026-06-29
> Автор:

Крупные фазы развития проекта с целями и критериями готовности. Детальные задачи — в
[backlog.md](backlog.md).

## Фазы

### Фаза 0. Подготовка и исследование ✅ сделано
- **Цель:** освоить SDK обеих камер, получить «живой» поток с каждой по отдельности.
- **Готово, когда:** RGB-поток (`Test.py`) и тепловой поток (`plug617_stream_probe`)
  стабильно запускаются и отображаются.

### Фаза 1. MVP захвата ✅ сделано
- **Цель:** единый сервис, запускающий и останавливающий поток с одной камеры.
- **Готово, когда:** есть общий интерфейс устройства; кадры доступны потребителю.

### Фаза 2. Две камеры вместе ✅ сделано
- **Цель:** одновременная работа RGB и тепловой; синхронизация по времени.
- **Готово, когда:** оба потока идут параллельно, кадры помечены временем.

### Фаза 3. API и выдача ✅ сделано
- **Цель:** внешний интерфейс (транспорт выбран в ADR), выдача кадров, вещание видео.
- **Готово, когда:** потребитель получает кадры через API; поток камер доступен по
  RTSP/RTP в H.264 (см. [ADR-0002](../02-architecture/decisions/0002-streaming-transport.md));
  доступны JSON-пресеты настроек (в здании / на улице / кастом); см.
  [../03-api/overview.md](../03-api/overview.md).
- **Итог (2026-07-10):** самописный NVENC→RTP/RTSP-поток ([ADR-0004](../02-architecture/decisions/0004-streaming-inhouse-nvenc.md)),
  управляющий канал TCP+JSON ([ADR-0006](../02-architecture/decisions/0006-control-protocol-tcp-json.md)) с живой
  сменой параметров, JSON-пресеты (indoor/outdoor/custom, load/save/list + стартовый),
  замер сквозной задержки. Проверено по прямому Ethernet — см.
  [эксперимент](../06-research/experiments/2026-07-10-latency-fps-tuning.md), [журнал](../07-journal/2026-07-10.md).

### Фаза 4. Совмещение и обработка
- **Цель:** калибровка и совмещение RGB ↔ тепло, базовая обработка/метрики.
- **Готово, когда:** кадры приведены в общую систему координат.

### Фаза 5. Стабилизация
- **Цель:** надёжность (reconnect), производительность (целевой FPS/latency),
  тесты, документация.
- **Готово, когда:** выполнены НФТ из [../01-requirements/non-functional.md](../01-requirements/non-functional.md).
